Om webbapplikationen

Denna webbplats är en frontend-applikation som använder ett REST API byggt med Node.js, Express och MongoDB. Applikationen hanterar arbetserfarenheter och visar CRUD-funktionalitet (Create, Read, Update, Delete).

Data skickas och hämtas via Fetch API och lagras i en NoSQL-databas (MongoDB).

Tekniker

Backend: Node.js, Express, Mongoose
Databas: MongoDB (hostad via Railway)
Frontend: HTML, CSS och JavaScript

Funktionalitet

Användaren kan se alla arbetserfarenheter, lägga till nya poster via ett formulär samt ta bort befintliga poster. All data valideras både i frontend och backend för att säkerställa att korrekt information skickas och sparas.

Slutsats

Projektet gav en tydlig förståelse för hur en modern webbapplikation byggs upp med separerad frontend och backend. En särskilt lärorik del var att koppla ihop MongoDB med ett REST API och förstå hur data flödar mellan klient och server.
